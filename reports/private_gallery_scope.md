# 私有步态库 Demo 能力边界

## 现在能做什么

当前 demo 可以真实完成这些事情：

1. 从真实视频中自动检测并跟踪单人轨迹
2. 为每条合格轨迹提取 silhouette 序列
3. 用当前 checkpoint 提取 gait embedding
4. 把样本写入私有步态库
5. 用新视频和私有步态库做匹配
6. 在 GUI 中展示：
   - 已录入 identity
   - 样本数量
   - track clip
   - silhouette 摘要
   - Top-K 候选
   - distance / score
   - 是否建议人工复核

## 现在不能承诺什么

当前 demo 还不能被表述成：

- 官方 benchmark 页面
- 最终业务系统效果
- 真实安防级识别系统
- 可直接上线的身份认证系统

原因很简单：

- 真实视频域和 CASIA-B 训练域有明显差异
- 前处理质量会强烈影响最终 embedding
- 私有库样本数目前通常很少
- 目前只是最小可演示系统，不是经过大规模实测的业务版本

## 对输入视频的要求

建议输入视频尽量满足：

- 单人、全身尽量完整
- 横向或斜后方走路，尽量有连续步态
- 相机别剧烈晃动
- 人不要太远，bbox 尺寸不要太小
- 光照不要太差
- 背景尽量简单
- 至少能提供一段连续有效 walking 序列

## 当前最容易卡住的地方

真实视频效果不好时，最常见瓶颈不在 checkpoint 本身，而在前处理：

1. 检测不到稳定 track
2. track 太短
3. silhouette 质量太差
4. 连续有效帧不够
5. 录入样本过少
6. 查询视频和录入视频差异过大

## 一句话总结

当前系统已经是“你自己的步态库识别 demo”，但它仍然是演示系统，不是最终业务系统。
