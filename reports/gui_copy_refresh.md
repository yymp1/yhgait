# GUI 文案优化说明

## 本轮改了哪些页面文案

这次只调整了用户可见文案，没有改功能逻辑、模型推理、训练配置或检索流程。

已统一优化的页面包括：

1. 首页标题与顶部说明
2. `样本录入` 页
3. `视频识别` 页
4. `效果分析` 页

## 统一了哪些词汇

本轮重点把研发口吻较重的表述收敛成更自然的展示用语：

- 系统名称统一为：`姿态识别系统`
- `人员录入 / 建库` 改为：`样本录入`
- `上传识别` 改为：`视频识别`
- `数据集分析（辅助）` 改为：`效果分析`
- `私有步态库` 改为：`样本库`
- `Identity` 改为：`人员编号`
- `track` 相关展示改为：`目标`、`目标片段`
- `silhouette` 相关展示改为：`目标轮廓摘要`
- `distance / score` 的展示改为：`相似度分数`、`参考分值`

## 怎样让真实视频识别流程更容易理解

本轮主要做了三件事：

1. 首页直接说明“先录入样本，再上传新视频识别”
2. 在 `样本录入` 和 `视频识别` 两个页面顶部补了一句简洁说明
3. 把按钮、区块名、表头都改成更直白的中文表达，让用户一眼看懂下一步该点哪里

## 哪些研发说明被弱化或移到辅助页

- 首页不再强调技术来源、协议、研究术语
- 主页面不再把研发分析内容放在用户第一视角
- 固定样本评估、训练阶段对比等说明集中到 `效果分析` 页

## 当前结果

现在这套界面更接近对外展示产品，而不是研发演示页。
