# 真实视频 Demo 的能力边界

## 它现在能展示什么

- 把一段真实视频送进检测 / 跟踪 / silhouette / retrieval 链路
- 让你看到：
  - 视频里抓到了哪些 track
  - 哪个 track 被自动选中
  - 当前 track 的 clip 和 silhouette 摘要
  - Top-K 检索候选
  - 每个候选的 `subject / type / view / distance / hit`

## 它现在不能证明什么

- 不能证明当前模型在真实业务里已经可用
- 不能把页面里的 Top-K 直接当成官方 benchmark 成绩
- 不能把一次 demo 的命中结果当成稳定线上指标
- 不能说明多人、遮挡、远距离、小目标场景已经被解决

## 它到底是什么

它是一个：

- 基于真实视频输入
- 基于当前真实 checkpoint
- 基于真实 `CASIA-B` gallery
- 复用现有 OpenGait embedding 与 retrieval 逻辑
- 用来观察“真实视频前处理 + 当前模型”联合作用的最小演示

它不是一个：

- 官方评测入口
- 业务级身份系统
- 可直接对外承诺精度的产品

## 为什么这个边界很重要

因为真实视频效果，往往不只是模型本身决定的，还被这些环节强烈影响：

1. 检测框是否稳定
2. 跟踪是否连续
3. silhouette 是否干净
4. 有效连续帧是否足够
5. 真实视频和 `CASIA-B` 的域差异有多大

所以这个页面的价值是：

- 帮我们看清“问题更像出在前处理，还是出在模型表征”

## 当前最适合怎么用

- 用它快速试一段真实视频
- 看自动选中的 track 是否合理
- 看 silhouette 序列是否像样
- 看 Top-K 候选是否有稳定聚集
- 如果效果不好，先排查前处理链路，再谈继续训练
