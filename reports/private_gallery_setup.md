# 姿态识别系统启动说明

## 这是什么

当前主界面已切换为“样本录入 + 视频识别”模式：

1. 先上传真实人物视频做录入建库
2. 系统自动做 track、silhouette、embedding
3. 把样本写入本地样本库
4. 再上传新视频做识别
5. 输出 Top-1 / Top-K 候选和人工复核提示

最重要的一句：

- 当前识别结果仅与本地样本库进行匹配。

## 页面结构

主页面有三个标签：

1. `样本录入`
2. `视频识别`
3. `效果分析`

其中真正的主流程是前两个标签；第三页只用于查看效果参考，不是主流程入口。

## 录入怎么用

在 `样本录入` 页：

1. 上传视频，或填写服务器上的本地视频绝对路径
2. 填写人员编号，例如 `001`、`张三`
3. 点击 `开始处理样本视频`
4. 查看自动生成的候选目标列表
5. 选择一个质量合格的目标
6. 点击 `保存当前目标为样本`

录入成功后，右侧会同步更新：

- 已录入人员列表
- 每位人员的样本数量
- 当前人员的样本明细

## 识别怎么用

在 `视频识别` 页：

1. 上传一段新视频，或填写服务器上的本地视频绝对路径
2. 点击 `开始识别`
3. 查看自动生成的候选目标列表
4. 选择要识别的目标
5. 查看：
   - 最相近人员
   - Top-K 候选
   - 相似度分数 / 参考分值
   - 是否建议人工复核
