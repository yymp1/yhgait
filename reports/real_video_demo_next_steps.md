# 真实视频 Demo 下一步优先建议

## 主建议

如果你要继续提升“真实视频 demo 效果”，最优先改的是：

- `silhouette / 序列质量`

而不是立刻继续训练。

## 为什么优先改这里

当前这条真实视频链路里，最脆弱的地方不是 checkpoint 加载，也不是 retrieval 本身，而是：

1. 检测框是否稳定
2. track 是否连续
3. silhouette 是否足够干净
4. 序列长度是否足够

这些环节一旦差，后面的 embedding 再好也会被拖垮。

## 最值得先做的一件事

把当前 `SelfieSegmentation` 的 silhouette 结果做一次可视化对照排查，并优先提升这一步的稳定性。

最实际的方向是：

- 优化 crop 策略
- 提高 mask 清理质量
- 改善连续有效帧筛选
- 必要时换成更适合全身行走目标的人体分割方案

## 在这之后再考虑什么

如果前处理质量已经稳定，再考虑：

1. 收集一小批真实视频 query 做固定对照集
2. 对比 `00500 / 01000` 在真实视频 query 上的变化
3. 再决定是否值得继续训练或做轻量适配
